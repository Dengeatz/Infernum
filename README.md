# Анализ и план дипломной работы "Разработка игры «Infernum» в жанре FPS Shooter" (Unity)

## Введение
### Актуальность
- Рынок видеоигр в 2025 году оценивается почти в **$197 млрд**.
- Жанр FPS — один из топ-3 самых популярных в мире.

Разработать и проанализировать прототип игры **«Infernum»** в жанре FPS на движке **Unity**.

1. Провести анализ предметной области и обосновать выбор технологий.

5. Выполнить тестирование и оценить результаты.

### Объект и предмет исследования
- **Объект:** процесс создания компьютерной игры в жанре FPS.
- **Предмет:** технологии, инструменты и методы разработки игры «Infernum» на Unity.

### Методы исследования

## Раздел 1. Теоретическая часть
### 1.1 Выбор движка: сравнение Unity vs Unreal
- **Unity преимущества:** низкий порог входа, огромное сообщество, Asset Store, производительность Unity 6 (выросла до 50%).
- **Unreal Engine** — мощнее, но сложнее для инди.

### 1.2 Технические требования к FPS
- **Производительность:** стабильный FPS.
- **Методы оптимизации (цифры из исследований):**
  - `GPU Instancing` → прирост **+10.9%**
  - `Static Batching` → **+20.4%**
  - `LOD (Level of Detail)` → **+380%** FPS
- **Рендеринг:** выбор конвейера.
  - **URP (Universal Render Pipeline)** — для производительности и широкого круга устройств.
  - **HDRP** — для высококлассной графики на мощном ПК.
- **Сетевой код (мультиплеер):**
  - Фреймворки: Mirror, Netcode for GameObjects.
  - Перспективная технология **DOTS** → 60+ FPS для тысяч объектов.

### 1.3 Архитектура игры
- Паттерн **MVC (Model-View-Controller)** — разделение данных, интерфейса и логики. Код становится читаемым и расширяемым.

- В 2025 году рынок шутеров — **$75.4 млн**, CAGR 12.8%.

- Доля FPS на российском рынке — **13%**.

### 2.2 Экономическое обоснование
- **Затраты (смета):**
  - Бытовые расходы

  - ПО, ассеты
  - Маркетинг
- **Ориентир:** самостоятельная разработка — от **100 тыс. руб./месяц**.

### 2.3 Модель монетизации
- Premium (платная игра)
- Free-to-play + внутриигровой магазин (косметика)
- Battle Pass

### 2.4 Оценка эффективности

- Использовать **калькулятор Steam** (комиссия 30% + налоги).
